<objective>
Rewrite the renderer-side favorites repository and electron client to use dedicated IPC channels, completing the migration from full-blob read-modify-write to targeted SQL operations.

Purpose: The old FavoritesRepository reads the ENTIRE FavoritesData blob from electron-store, modifies it in memory, and writes the ENTIRE blob back for every mutation. This plan rewrites it to call the 11 dedicated IPC channels created in Plan 43-01, where each channel performs a targeted SQL operation. The electron.client.ts gets new favorites wrapper methods. The old favoritesData route is removed from store.handler.ts keyToTable().

Output:
- `src/clients/electron.client.ts` -- 11 new favorites* methods wrapping IPC calls in IpcResponse<T> format
- `src/repositories/favorites.repository.ts` -- Complete rewrite using electronClient.favorites*() calls
- `electron/main/ipc/handlers/store.handler.ts` -- Remove 'favoritesData' from keyToTable() switch
</objective>

Existing electronClient pattern (from src/clients/electron.client.ts):

```typescript
class ElectronClientImpl {
  private isAvailable(): boolean { return typeof window !== 'undefined' && !!window.electronAPI }
  private createErrorResponse<T>(code: string, message: string): IpcResponse<T> { ... }

  // Each method follows this pattern:
  async methodName(params): Promise<IpcResponse<T>> {
    if (!this.isAvailable()) return this.createUnavailableResponse<T>()
    try {
      const result = await window.electronAPI.methodName(params)
      if (result.success) return { success: true, data: result.data as T }
      return { success: false, error: result.error || { code: '...', message: '...' } }
    } catch (error) {
      return { success: false, error: { code: '...', message: String(error) } }
    }
  }
}
export const electronClient = new ElectronClientImpl()
```
