# Plan 45-03: Clean Preload and ElectronClient

## Objective

从 preload 脚本和 electronClient 中移除 `saveSettings`/`loadSettings` 方法和桥接。

## Context

- `preload/index.ts` 暴露了 `saveSettings` 和 `loadSettings` 桥接
- `electron.client.ts` 有对应的 `saveSettings()` 和 `loadSettings()` 方法
- 这些方法已无消费者，可安全删除

## Tasks

### Task 1: Remove Preload Bridge for saveSettings/loadSettings

<read_first>
- electron/preload/index.ts
</read_first>

<action>
修改 `electron/preload/index.ts`：

1. 从 ElectronAPI 接口（第 56-57 行）删除：
```typescript
saveSettings: (settings: any) => Promise<{ success: boolean; error?: string }>
loadSettings: () => Promise<{ success: boolean; settings: any | null; error?: string }>
```

2. 从 electronAPI 对象（第 204-211 行）删除：
```typescript
saveSettings: (settings: any) => {
  console.log('[Preload] saveSettings called')
  return ipcRenderer.invoke(IPC_CHANNELS.SAVE_SETTINGS, settings)
},
loadSettings: () => {
  console.log('[Preload] loadSettings called')
  return ipcRenderer.invoke(IPC_CHANNELS.LOAD_SETTINGS)
},
```
</action>
