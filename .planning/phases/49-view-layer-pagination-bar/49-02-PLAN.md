2. 修改 handleToggleFavorite 函数:

```typescript
/**
 * 处理收藏按钮左键点击 - 快速添加/移除默认收藏夹
 */
const handleToggleFavorite = async (item: WallpaperItem): Promise<void> => {
  const defaultCollection = getDefault()
  if (!defaultCollection) {
    showWarning('请先设置默认收藏夹')
    return
  }

  // 检查是否已在默认收藏夹中
  if (isInCollection(item.id, defaultCollection.id)) {
    // 已在默认收藏夹中，移除
    await removeFavorite(item.id, defaultCollection.id)
    // 更新 is_favorite 为 0（未收藏）
    updateItemFavoriteStatus(item.id, 0)
    showSuccess(`已从"${defaultCollection.name}"移除`)
  } else {
    // 不在默认收藏夹中，添加
    await addFavorite(item.id, defaultCollection.id, item)
    // 更新 is_favorite 为 1（收藏到默认收藏夹）
    updateItemFavoriteStatus(item.id, 1)
    showSuccess(`已添加到"${defaultCollection.name}"`)
  }
}
```

**is_favorite 值说明 (基于 Phase 47 D-02):**
- `0`: 未收藏
- `1`: 收藏到默认收藏夹
- `2`: 仅收藏到其他收藏夹

<acceptance_criteria>
- 收藏成功后，currentPageData 中对应项的 is_favorite 更新为 1
- 取消收藏后，currentPageData 中对应项的 is_favorite 更新为 0
- 更新后壁纸卡片上的心形图标立即反映新状态
- 不触发 API 重新请求
</acceptance_criteria>

### Task 2: 处理 CollectionDropdown 操作后的状态同步

**目标:** 处理通过下拉菜单添加到非默认收藏夹的情况

<read_first>

</read_first>

**实现要点:**

1. 分析 CollectionDropdown 的操作流程:
   - 用户右键点击心形按钮 → 打开下拉菜单
   - 选择收藏夹 → 触发 add 操作
   - 当前实现：useFavorites.add() 被调用

2. 需要在 CollectionDropdown 操作后也同步状态

3. 方案 A — 在 OnlineWallpaper.vue 中监听 favorites 变化:
```typescript
import { watch } from 'vue'

// 监听 favorites 变化，同步更新 currentPageData
watch(
  () => favorites.value,
  (newFavorites) => {
    // 仅在当前页面有数据时处理
    if (currentPageData.value.data.length === 0) return

    // 遍历当前页的壁纸，检查收藏状态是否需要更新
    currentPageData.value.data.forEach((item) => {
      const favRecords = newFavorites.filter(f => f.wallpaperId === item.id)
      let newStatus = 0

      if (favRecords.length > 0) {
        const defaultColId = defaultCollectionId.value
        const inDefault = favRecords.some(f => f.collectionId === defaultColId)
        newStatus = inDefault ? 1 : 2
      }

      if (item.is_favorite !== newStatus) {
        updateItemFavoriteStatus(item.id, newStatus)
      }
    })
  },
  { deep: true }
)
```

4. 方案 B — 使用事件系统（如果 CollectionDropdown emit 事件）:
   - 检查 CollectionDropdown 是否有 @added / @removed 事件
   - 如果有，在事件处理中调用 updateItemFavoriteStatus

**推荐方案 A** — 更简单且不依赖 CollectionDropdown 的实现细节

<acceptance_criteria>
- 通过下拉菜单添加到默认收藏夹 → is_favorite 更新为 1，心形变红
- 通过下拉菜单添加到其他收藏夹 → is_favorite 更新为 2，心形变蓝
- 通过下拉菜单从收藏夹移除（且无其他收藏）→ is_favorite 更新为 0，心形变空心
- 从默认收藏夹移除但仍在其他收藏夹 → is_favorite 更新为 2，心形变蓝
</acceptance_criteria>

### Task 3: 验证三态心形显示

**目标:** 确保 is_favorite 字段更新后心形图标正确显示三种状态

<read_first>
- src/components/WallpaperList.vue (heartState 函数，第 207-209 行)
- src/utils/heart.ts (getHeartState 函数)
- src/types/domain/wallpaper.ts (WallpaperItem.is_favorite)
</read_first>

**验证要点:**

1. WallpaperList.vue 中的 heartState 函数使用 wallpaperCollectionMap:
```typescript
const heartState = (id: string): HeartState => {
  return getHeartState(id, props.defaultCollectionId, props.wallpaperCollectionMap)
}
```

2. 当前实现问题:
   - heartState 依赖于 wallpaperCollectionMap（从 favorites 计算）
   - 而非依赖于 item.is_favorite 字段

3. 需要确认的是：
   - is_favorite 字段在 Phase 47 中由 Service 层注入
   - 但 WallpaperList 当前使用的是 wallpaperCollectionMap 计算心形状态
   - 两者需要保持一致

4. **关键发现:** 当前 OnlineWallpaper.vue 中的 wallpaperCollectionMap 是从 favorites 计算的:
```typescript
const wallpaperCollectionMap = computed(() => {
  const map = new Map<string, string[]>()
  for (const fav of favorites.value) {
    const ids = map.get(fav.wallpaperId)
    if (ids) {
      ids.push(fav.collectionId)
    } else {
      map.set(fav.wallpaperId, [fav.collectionId])
    }
  }
  return map
})
```

5. **结论:** wallpaperCollectionMap 已经响应式地跟随 favorites 变化，因此：
   - 收藏操作 → favorites 更新 → wallpaperCollectionMap 更新 → heartState 更新
   - is_favorite 字段的更新是额外的优化，确保缓存数据一致性
   - 两者需要同步更新

- 收藏到其他收藏夹（非默认）→ 心形显示蓝色实心
- 未收藏 → 心形显示空心
- 状态变化立即反映，无需刷新页面
</acceptance_criteria>
